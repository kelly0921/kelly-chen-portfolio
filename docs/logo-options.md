# Logo Options

These are alternate logo directions for Kelly's portfolio. The active site logo is `public/assets/kelly-logo.svg`, currently using the Cream Refined direction.

## Options

- `public/assets/logo-options/kelly-logo-option-a-editorial.svg`
  - Fashion/editorial monogram with warm ink, rose, cream, and one small honey accent.
- `public/assets/logo-options/kelly-logo-option-b-ribbon.svg`
  - Softer ribbon-like KC mark that keeps some technical structure without feeling like an app icon.
- `public/assets/logo-options/kelly-logo-option-c-minimal.svg`
  - Minimal luxury badge with dark background; strongest contrast, most polished, least pastel.
- `public/assets/logo-options/kelly-logo-option-c-warm-ink.svg`
  - Option C with softer warm ink background.
- `public/assets/logo-options/kelly-logo-option-c-rose.svg`
  - Option C with a deep rose background.
- `public/assets/logo-options/kelly-logo-option-c-periwinkle.svg`
  - Option C with a muted periwinkle background.
- `public/assets/logo-options/kelly-logo-option-c-teal.svg`
  - Option C with a deep teal background.
- `public/assets/logo-options/kelly-logo-option-c-cream.svg`
  - Option C with a cream background and dark letters.
- `public/assets/logo-options/kelly-logo-option-c-cream-tuned.svg`
  - Refined cream version with a lighter premium outline and cleaner small-size contrast.
- `public/assets/logo-options/kelly-logo-option-d-stamp.svg`

- `public/assets/logo-options/kelly-logo-option-e-script.svg`
  - Light script-inspired line mark; more personal and airy, still structured.

## Current Preference Notes

Kelly selected the Cream Refined direction from Option C. Keep the overlapping `KC` concept fashionable, warm, minimal, and integrated with the site's cream/pastel branding. Avoid unexplained decorative lines, busy tech diagrams, and generic app-badge styling.

Keep `public/assets/kelly-logo-mark.svg` as the compact website mark asset, even when the active site references `public/assets/kelly-logo.svg`.
