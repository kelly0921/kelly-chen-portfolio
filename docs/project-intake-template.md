# Project Portfolio Intake Template

Use this prompt in each project chat when collecting information for the portfolio Projects section.

```text
I am updating the Projects section of my personal portfolio. Please summarize this project in a way that helps someone quickly understand the product, technical depth, and my role.

Give me the information in this structure:

1. Project Name
What should this project be called publicly?

2. One-Line Summary
A concise sentence that explains what the project does and who it helps.

3. Problem
What problem does this project solve? Why does it matter?

4. Target Users
Who is this built for?

5. My Role
What did I personally design, build, decide, or lead?

6. Core Features
List the most important features, focusing on user-facing value.

7. Technical Details
What stack, architecture, APIs, databases, tools, automation, or technical decisions are important to mention?

8. Product Thinking
What product decisions shaped the project? What tradeoffs or user experience choices mattered?

9. Current Status
Is this live, in progress, prototype, local MVP, paused, or planned?

10. What I Learned
What did this project teach me technically, product-wise, or strategically?

11. Portfolio-Friendly Case Study
Write a polished portfolio version with these sections:
- Overview
- Problem
- Approach
- My Role
- Technical Highlights
- Current Status
- What I Learned

12. Short Card Copy
Write a version suitable for a project preview card:
- Title
- 1-sentence description
- 3-5 tags
- Best CTA label, such as "View Case Study," "View Demo," "Explore Concept," or "Interested in This Idea?"

13. Missing Information
Tell me what details are missing or uncertain so I can fill them in before publishing.
```

Suggested projects to run through this template:

- BeamCash
- SkanPay
- AI-assisted website workflow / WebPilot
- QR payment concepts
- Future tools from content, such as an Opportunity Signal Tracker or Conference Leverage Planner
